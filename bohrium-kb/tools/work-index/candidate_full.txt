# Infer a finite-horizon poisoning balance from catalytic-lattice KMC

## Scientific background

Consider the irreversible surface reaction

```text
A(g) + B(g) → AB(g).
```

The gas reservoir has fixed composition: `X_A` is the mole fraction of A and
`1-X_A` is the mole fraction of B. These are reservoir fractions, not surface
coverages. The surface fractions are `theta_A`, `theta_B`, and `theta_empty`.

Adsorption occurs only after an impact on an empty site and then only with the
species- and material-dependent sticking probability. Neighbouring unlike
adsorbates react and desorb immediately. Unequal effective adsorption supplies
therefore shift the competition between an absorbing A-covered surface and an
absorbing B-covered surface.

On a finite stochastic lattice, a trajectory can remain reactive for a long
time and still poison later. Survival to the requested horizon is
right-censoring, not evidence of an eternal steady state.

Your task is to estimate a finite-horizon A/B poisoning balance from genuine
stochastic simulation, test effective-supply predictions on monometallic and
checkerboard-bimetallic surfaces, and assess one matched finite-size
comparison. The problem is self-contained; no source paper is required.

## Frozen microscopic model

The surface is an initially empty periodic `L×L` square lattice. A site is
encoded as empty, A, or B. One Monte Carlo cycle is `L²` impact attempts.

For each impact:

1. Draw one site uniformly from all `L²` sites.
2. If it is occupied, end the impact without drawing a species or sticking
   variate.
3. At an empty site, draw A with probability `X_A`, otherwise B. Count this as
   an A or B arrival.
4. Draw adsorption acceptance using the chosen species' sticking probability
   on that fixed site type. Count a successful acceptance as an adsorption.
5. After adsorption, enumerate unlike axial neighbours in the order left,
   right, up, down, with periodic wrapping.
6. If at least one unlike neighbour exists, choose one uniformly, remove it
   and the new adsorbate, and count exactly one reaction. If there is exactly
   one unlike neighbour, select it without another random draw.

For a monometallic surface the coefficients are `s_a` for A and `s_b` for B.

For a bimetallic surface, `L` is even. Site `a` has
`(row+column) mod 2 == 0`; site `b` has odd parity. In `s_ij`, the first
subscript is adsorbing species and the second is site type:

```text
             site a          site b
species A      s_aa       s_ab = 1-s_bb
species B  s_ba = 1-s_aa      s_bb
```

This checkerboard and complementarity are assumptions of this task, not a
universal catalyst law.

The lattice poisons immediately when an impact leaves all sites occupied by
one species. Stop that trajectory at once. If poisoning occurs on the `k`-th
impact of one-based cycle `c`, record

```text
poisoning_cycle = completed_cycles = (c-1) + k/L².
```

An unpoisoned run stops after cycle `T`, with `completed_cycles=T`.

## Observables and units

Use the following canonical categories:

- `poison_species`: `A`, `B`, or the empty string for a censored run;
- `state`: `active`, `right_censored`, `poisoned_a`, or `poisoned_b`;
- `balance_status`: `resolved` or `unresolved`;
- booleans: JSON/CSV boolean values such as `true` and `false`.

`time_series.csv` must contain the end-of-cycle state for each requested
`record_cycles` value that the trajectory reaches. Always include the terminal
row: cycle `T` for a survivor or the fractional poisoning time for a poisoned
run, even when that time was not requested. Do not add synthetic rows after
poisoning. If the previous emitted time is `t_0`, define

```text
window_reaction_rate
  = reactions accumulated on (t_0,t] / (L² * (t-t_0)).
```

`late_reaction_rate` uses the last
`min(late_window_cycles, number of reached cycle slices)` slices, including a
final fractional slice, and is total reactions divided by `L²` times their
total duration. Both rates therefore have units reactions per site per Monte
Carlo cycle.

At each `X_A`, aggregate the seed outcomes as follows:

```text
p_a_poisoned       = n_A / n
p_b_poisoned       = n_B / n
d_poisoning        = (n_A - n_B) / n
survival_probability = n_censored / n
restricted_mean_lifetime = mean(min(poisoning_cycle, T)).
```

`se_d_poisoning` is the ordinary sample standard error of outcome codes
`+1` (A poison), `-1` (B poison), and `0` (censored). Other `se_*` fields are
ordinary sample standard errors of the named seed-level quantities. Use an
explicit justified 95% interval for survival (Wilson is acceptable) and for
the balance.

For a canary checkpoint, set `state_sha256` to the SHA-256 of the row-major
lattice bytes after encoding empty/A/B as unsigned bytes `0/1/2`; write
lowercase hexadecimal.
`checkpoints.csv` contains one row for each emitted deterministic-canary
time-series row in the supplied input. Statistical-production cases do not
produce checkpoint rows.

## Scientific estimand

For fixed `L`, horizon `T`, and composition `x`, define

```text
D_L,T(x)
  = P(A-poisoned by T | X_A=x)
  - P(B-poisoned by T | X_A=x).
```

The simulation-derived apparent balance is a negative-to-positive crossing of
`D_L,T(x)=0`. Estimate it from the independent outcomes and give an uncertainty
interval. You may use bootstrap plus monotone regression, a binomial model, or
another justified method. Report `bracket_low` and `bracket_high` as simulated
compositions supporting the crossing. `x_grid_resolution` is the minimum
positive spacing in the case's sorted grid.

If the observed outcomes do not support a crossing, report `unresolved` and
leave the simulated balance, its interval, bracket, and every corresponding
prediction residual blank. Never substitute a theoretical value. Survival and
late reaction activity are required diagnostics, not alternative definitions
of the balance. For tied diagnostic maxima, use the smallest `X_A`.

## Research questions

### 1. Monometallic effective supply

Start from

```text
J_A proportional to X_A s_a
J_B proportional to (1-X_A) s_b.
```

Derive a balance hypothesis by equating the supplies. Compare it with the
simulation-derived balances for symmetric and asymmetric sticking pairs and
explain the direction of the shift and finite-horizon limitations.

### 2. Checkerboard bimetallic model

Construct and freeze before interpreting holdouts:

- a simple one-channel, pooled-site, or mean-sticking baseline; and
- a site-resolved effective-supply prediction that respects the two
  sublattices and the four sticking channels above.

The final site-resolved formula is deliberately not supplied. Deriving a
physically consistent rule and using it on unseen parameter combinations is
part of the research task. For every bimetallic case, report both predictions,
compare their residuals, and test:

- label exchange: paired cases sharing `label_exchange_group` must transform
  consistently under A/B exchange;
- homogeneous limit: when `s_aa+s_bb=1`, both site types present the same
  sticking coefficient to each species.

### 3. Matched finite-size robustness

Cases sharing an `anchor_group` form a matched comparison. Sticking
parameters, horizon, grid, and replicate count are fixed; only `L` changes.
Compare estimates and intervals without claiming a thermodynamic-limit
extrapolation.

## Deterministic canary gate

Cases marked `deterministic_canary` are an unscored event-kernel eligibility
gate. Each required variate is the next scalar `rng.random()`. Map a site draw
as `floor(u L²)`, choose A when `u<X_A`, accept when `u<S`, and select neighbour
`floor(u n_unlike)` in the stated enumeration. The no-draw branches above are
load-bearing. Production trajectories are not compared bitwise.

## How you are scored

The checker first validates the frozen entry point, output contract, and
deterministic PCG64 event-kernel checkpoints on the undisclosed mixed input. A
failed eligibility gate receives reward `0`. `run_manifest.json` must exist,
parse as JSON, and contain its required keys, but value-level provenance
mismatches (for example an incorrect or incomplete declared hash) are a soft
penalty inside trajectory validity rather than an automatic zero.

Eligible submissions receive four equally weighted continuous component
scores:

- trajectory validity and cross-file scientific accounting: 25%;
- statistical poisoning, survival, and activity outcomes: 25%;
- simulation-supported balance estimation and uncertainty: 25%;
- monometallic/bimetallic theory, holdouts, limits, and size robustness: 25%.

The layers are evidence-linked. Statistical outcomes and simulated balance
claims receive credit only when the submitted production trajectories support
their case/seed coverage, accounting, time series, and recomputed aggregates.
Analytical theory may receive limited standalone credit, but its residual,
holdout, and robustness claims must be grounded in the submitted simulation.
Correct canary replay by itself is therefore not sufficient for a high score.

Large-scale production results are compared statistically with independent
reference ensembles. They are not required to replay a single reference
trajectory bit for bit.
