# 构建流水线

> category: core | readTime: 10 min read | source: https://play.bohrium.com/api/docs/building-pipelines

将技能组合成流水线
流水线是一系列有序的技能，用于完成复杂任务。流水线是智能体编排多步骤科学工作流的主要方式。
流水线结构
每条流水线定义：
- 步骤——有序的原子技能列表
- 数据流——一个步骤的输出如何传递给下一个步骤
- 检查点——在继续之前暂停验证的位置
- 回退策略——某步失败时的处理方式

设计原则
- 从便宜到昂贵——在投入昂贵计算之前，先用简单案例验证
- 快速失败——尽早检查前置条件。不要用错误的机理跑十小时模拟。
- 记录一切——每步都应追加到轨迹中，创建完整的审计线索
- 幂等步骤——失败后重新运行应产生相同结果

示例：论文复现流水线
1. 解析论文 → 提取文本、图表、参数
2. 提取运行卡片 → 机器可读的运行条件
3. 验证化学 → 零维点火延迟检查
4. 参考火焰 → 一维火焰速度 vs. Cantera
5. 目标模拟 → 完整计算
6. 对比与评分 → 与论文图表进行 SSIM 对比
Fork 流水线
Fork 现有流水线以适应你的使用场景。常见修改：
- 替换某个步骤（如用 VASP 替代 Cantera 进行 DFT 计算）
- 增加步骤（如插入 Soret 扩散验证）
- 调整检查点（如更严格的收敛标准）

在工具页面分享你修改后的流水线，供他人使用。
