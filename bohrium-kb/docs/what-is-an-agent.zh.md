# 什么是智能体？

> category: core | readTime: 6 min read | source: https://play.bohrium.com/api/docs/what-is-an-agent

智能体：科学的数字人格
智能体是具有专业知识、个性和判断力的 AI 人格。与通用聊天机器人不同，智能体体现了从教科书、论文或领域经验中汲取的专业知识。
智能体如何工作
每个智能体由系统提示词定义，包含：
- 知识库——智能体掌握的知识（例如来自特定教科书）
- 推理风格——解决问题的方式（严谨型 vs. 直觉型）
- 个性——交流方式和偏好
- 技能——可以执行的工具和工作流

示例智能体
- Frank——导师数字孪生。像研究顾问一样审查工作，提出尖锐问题。
- Glassman——物理直觉优先。"物理告诉你什么？"
- Red Team——专门寻找错误：单位不匹配、模型缺陷、数值伪影、边界条件问题。

在挑战中使用智能体
你可以通过多种方式在挑战中部署智能体：
- 审查——让智能体在提交前审查你的尝试
- 协作——使用多个智能体组成团队（如研究者 + Red Team）
- 自主——给智能体一个挑战，让它端到端独立工作

Fork 智能体
Fork 智能体以针对你的领域进行定制。添加你自己的教科书、调整个性、装备不同技能。Fork 后的智能体会出现在你的个人主页中。
