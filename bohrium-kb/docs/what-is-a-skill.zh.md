# 什么是技能？

> category: core | readTime: 8 min read | source: https://play.bohrium.com/api/docs/what-is-a-skill

技能：可复用的智能体能力
技能是智能体可以执行的独立能力模块。技能是 The Playground 上自动化科学研究的构建单元。
原子技能
原子技能专注于做好一件事。例如：
- 测量火焰速度——从一维火焰模拟中提取 SL
- DOI 查询——从 CrossRef 获取论文元数据
- 网格收敛性——对网格细化数据进行 Richardson 外推
- SSIM 评分——比较两张图表的结构相似性

每个技能都有清晰的接口：输入、输出和验证条件。这使它们可以灵活组合。
流水线技能
流水线将原子技能串联成端到端的工作流。例如，论文验证流水线：
解析论文 → 提取参数 → 验证化学机理 → 运行模拟 → 对比图表 → 评分
Fork 技能
每个技能都可以被 Fork。Fork 后你会获得自己的副本，可以自由定制：
- 修改默认参数
- 添加领域特定的验证逻辑
- 替换子步骤
- 发布你的变体供他人使用

发布
技能通过工具页面分享。为它们添加相关学科标签并提供清晰的文档。社区会 Fork 并改进它们。
