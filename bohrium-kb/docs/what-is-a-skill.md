Skills are the building blocks of automated science on The Playground.\nAtomic Skills\nAn atomic skill does one thing well. Examples:\n- Measure Flame Speed \u2014 extract SL from a 1D flame simulation\n- DOI Lookup \u2014 fetch paper metadata from CrossRef\n- Grid Convergence \u2014 run Richardson extrapolation on mesh refinement data\n- SSIM Score \u2014 compare two figure images for structural similarity\n\nEach skill has a clear interface: inputs, outputs, and validation criteria. This makes them composable.\nPipeline Skills\nA pipeline chains atomic skills into an end-to-end workflow. For example, the Paper Verification pipeline:\nParse Paper \u2192 Extract Parameters \u2192 Validate Chemistry \u2192 Run Simulation \u2192 Compare Figures \u2192 Score\nForking Skills\nEvery skill can be forked. When you fork a skill, you get your own copy that you can customize:\n- Change default parameters\n- Add domain-specific validation\n- Swap out sub-steps\n- Publish your variant for others to use\n\nPublishing\nSkills are shared through the Tools page. Tag them with relevant disciplines and provide clear documentation.
