# 防卡题强制换角度协议

核心经验：分数无法提高时，**抛弃原方法从新角度尝试**是突破的唯一共性机制（S4 实战 5 次突破全部如此），但换角度必须基于判官行为证据，而非盲目重写（13 次无效换角度全是等价壳内换呈现）。

## When to Use

- 任何解题代理分数卡死时（**无权自行收工，必须触发本协议**）
- 判词连续两轮同一负面表述
- 我方与全场最高档差距 ≥2 档且 2 小时无进展
- **高分未满（≥90%）却定位不到丢分分量**——先 `platform-scorecard-analyze` Step 5 分量级分解，分解不出再换角度
- **本地复核饱和**（同分量 ≥3 轮无新信息）却仍在本地打转——立即换轨

## Step 1 — 卡死检测（量化，已收紧）

- **同字段轴 2+ 变体 harbor 纹丝不动 + 本地饱和**（同一分量本地复核 ≥3 轮无新信息）；
- 或连续 3 轮无任何提升；
- 或判词重复（"did not find complete, genuinely-derived" ×2）；
- 或 **高分未满却定位不到丢分分量**（→ 先执行 `platform-scorecard-analyze` Step 5 分量级分解，再决定换角度还是定点修复）。

> **收紧说明**：触发从"同轴 3+ 变体"收紧到"同轴 2+ 变体 + 本地饱和"。KMC 95.75 教训——"本地反复复核"是伪进展陷阱；本地复核饱和后，同轴再动一轮的期望收益已趋零，应立即换轨（oracle 差分 / 红队 / 换角度），而不是第 3 次盲试。

## 轴台账（Axis Ledger，必备产物）

每次 A/B 实验后，在判官信号卡里维护一张**轴台账**（每轴一行，附 attempt id 证据）：

```
轴 | 假设 | attempt_id | harbor 增量 | 结论
----|------|-----------|-----------|------
mono.lex | 检查列应为 not_applicable | 28637 | 0.000 | 证伪（非扣分点）
bi.lex   | ... | ... | ... | 未验证
```

- **卡死判定客观化**：台账里同轴 ≥2 行且增量全为 0 → 客观卡死，触发本协议（不再凭"感觉"判断）。
- **防重复**：已证伪的轴不得再试（除非有新证据）；已验证有效的轴锁定不再动。
- **交接物**：换人时轴台账随资产一并移交，新代理不得重走已证伪的轴。

## Step 2 — 判官信号挖掘（换角度的弹药）

1. **判词**：scoringDetails 原文（"leaning on paper"=引用论文被罚；"not genuinely-derived"=canonical 绑定；"Solid—refine"=完备性问题）。
2. **档位对称性**：全场分数分布（谁在哪个档、档间差距）→ 我方与相邻档的差距在哪。
3. **字段响应矩阵**：哪些字段 A/B 动过、怎么动、哪些字段**从未动过**——从没动过的字段就是最大嫌疑（split 45 变体后才发现没动过 sigma_eff 的因子 2）。
4. **题面逐字重读**：尤其 §5 评分契约的"排他声明/形式要求/保留名/词表"——friday 三代理集体漏读 §3.3 "no spin-average"。

## Step 3 — clean-room 红队（强制）

新代理**只读题面原文+数据，禁止读任何旧 REPORT/EXPLORATION**（防止错误结论传染），指令强制：
1. 逐字翻译 §5 评分契约成自建 verifier（jarvis 法——判官 reference 反推）。
2. 列出所有排他声明、形式要求、保留名清单。
3. 用"判官 reference 最省事写法"（而非最严谨写法）重推——jarvis 裸值 4 就是这么来的。
4. 产出与现解法的差异清单（专找集体盲区）。

## Step 4 — 差异化视角题库（选未用过的视角上任）

- 裸值坐标系（不角平均/不学术化，读字段名字面）
- 保留名 canonical 记号（用题面保留名而非展开式）
- 数值代入验证（多参数集数值表）
- 表示形式轴（分数 vs 小数双写、LaTeX）
- 论文引用清除（trace 与答案中零论文引用）
- 参数化轴相变（换基/换变迹/换增强指数，找悬崖峰）
- 数据反演（直接从数据逆向 hidden truth，不猜参数）
- 异质模型对撞（spec 驱动 vs 论文对齐两种推理风格）

## Step 4b — 多模型异质审阅（融合自平台 /brainstorm 技能）

卡死时让**多个不同模型**（GPT/Claude/Gemini/Qwen/Kimi 等可用者）并行审阅同一份答案/题面，按角色与风格参数化：
- 角色（--role）：`scientist`（复现可信度）/ `red-team`（找致命缺陷）/ `visionary`（5 年视角）/ `agent-developer`（参赛者视角）。
- 风格（--style）：`review`（必要性→设计质量→改进）/ `critique`（致命缺陷→隐藏假设→不舒服的问题→救援）/ `debate`（最强反对立场）/ `brainstorm`（对→缺→大胆想法→优先级）。
- 汇总协议：**共识**（各模型一致点）→ **独特洞察**（仅一个模型提出）→ **冲突**（谁更强）→ **行动项**。
- 价值：绕过"同一模型族的思维定式传染"（split 三代理同为学术框架就是教训）；异质模型常能给出原框架外的假设（如"裸值 4"就来自不参与角平均训练的推理路径）。

## 禁卡死条例（写入每个解题代理）

1. 禁止"归因随机性/不可见后收工"——必须先完成信号挖掘与 clean-room 重读。
2. 禁止只在等价壳内穷举呈现变体。
3. 禁止未读 §5 评分契约就动手。
4. 旧 REPORT 结论（"天花板""非确定性"）必须附 attempt id 证据，新代理有权挑战。
5. **禁止把"本地复核饱和"当进展**——同分量本地复核 ≥3 轮无新信息即判本地饱和，必须换轨（oracle 差分诊断 / 红队 / 换角度），不得继续本地打转（KMC 95.75 教训）。

## 实战实例（可对照）

| 卡死题 | 原方法 | 换角度 | 结果 |
|---|---|---|---|
| twist | 6 次公式尝试 | 机械重建系数+正 q | 100 |
| uv | 单字段 A/B 穷尽 | 角平均因子 2/3 入 coefficient | 42（最高档） |
| split | 45+ 变体 | jarvis 裸值+保留名 → 爬分因子 2 | 81.55 |
| DeepHAM trace | 13 次 trace 实验 | 去论文引用 | 92.75 |
| 超声 | Hann 轴卡死 | Tukey 轴相变 | 93.3 |
