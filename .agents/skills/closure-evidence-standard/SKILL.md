# 封板证据标准（Closure Evidence Standard）

"当前实现天花板" ≠ "问题天花板"。solver 建议收关/封板时，先过本标准的证据门槛——07 止损过早（0→16.55 续战破壁）是最大教训：本地曾达 −16.7（rel 0.148），"FCNN 天花板 rel 0.28"是伪结论。

## When to Use

- solver 建议收关/封板/止损时（**总负责人裁决前强制核对此清单**）
- 出现"结构性不可达""天花板""封顶"类结论时
- 练习轮/无时间压力的赛段收口时

## 封板三问（先答，任一不满足 = 不是封板）

1. **场上有人在你上面？**——有人 = 头寸已被证明可达，不是封板；"他们额外分哪来的"是合法研究问题（对手分数 = 已证明可达）。
2. **多个独立 attempt 证伪还是只有你？**——只有你 = 你方法的问题，不是问题天花板。两个以上**真正不同**的 attempt 落同分（同一想法重发算一次）才可信。
3. **本地/历史是否曾达更高值？**——曾达 → 继续追，**禁止以预算/止损封板**。先 grep 本地/前代理 REPORT 的"曾达更高值"记录 + 精确反推配置再复现。

## 真天花板核对清单（07 教训细化，全过才算封板证据充分）

- [ ] **曾达更高值记录**：grep 本地/REPORT 有无更高值（07 有 −16.7 记录 → 天花板论直接错误）
- [ ] **反推复现过**：是否精确反推该更高值的配置（网络/采样/objective/优化器）并本地复现命中？（07：train_impt.py importance 采样 |ψ_GS|² 才是关键，非三层 FCNN 架构）
- [ ] **采样 regime 共享遗漏**：多方法触顶是否因**共享同一采样假设**（都从自身 |ψ|² 或 uniform），漏了不同采样 regime？
- [ ] **判分器两轨确认**：是否确认判分器真不接数值？"No per-challenge grader"不导向——必须通过当前题面与只读 live 证据核对 ARM/worker 路径；`worker-submit-chain` 在 Codex/ZCode 中均不可用，ZCode 唯一提交通道 = `work/_template/submit_bundle.py` + 仓库提交门钩子。
- [ ] **止损口径**：练习轮按**额度见底**收口，不按时间/回合止损（"跑了 N 小时"不是封板理由）。

## 封板条件（全部满足才可封板）

1. 多轴证伪（每轴附 attempt id 证据 + 轴台账）
2. 提交级证据（非仅本地/推断）
3. 无已知上升路径（考古、regime、两轨都核对过）
4. 封板结论标 `⚠ 可重测`（下轮零成本重验）；prohibition 类规则正常工作永不重测它——但规则本身阻止反驳实验，是最危险的规则，须谨慎立规

## 坑

- **"当前实现天花板" ≠ "问题天花板"**：07 rel 0.28 伪天花板——本地曾达 −16.7/rel 0.148，importance 采样破壁 0.171@4k。
- **时间止损 ≠ 额度止损**：练习轮语境下"预算/时间"不能作为封板理由；与用户对齐止损口径后再执行。
- **判分器"不接数值"需实证**：ARM 全 0 + "No per-challenge grader" 可能是提交路径问题（07 三次 ARM 全 0 后 worker 链 16.55）。

## 与相关技能的关系

- `unstuck-switch-angle` = 卡死时换角度（封板是换角度的终点判定：多轴证伪后才封，否则继续换角度）。
- 两轨确认只能记录为待验证假设；不得把不存在的 `worker-submit-chain` 当作已启用能力。
- `competition-coordinate` = 总负责人裁决流程（封板结论进决策日志，标 ⚠ 可重测；ZCode 单会话模式下由解题会话自行裁决并记录）。

## 实证

- 07：止损过早（"FCNN 天花板 rel 0.28"）→ 用户纠正 → 续战：worker 链 16.55（29168）、bohr importance 长训破壁 0.171@4k（23228699）。
- 用户纠正原则："本地曾达更高值 = 天花板论不成立"，练习轮按额度止损非时间止损。
